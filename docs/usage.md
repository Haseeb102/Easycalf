# EasyCalf User Guide

## Getting Started

### 1. User Management
- Admin can approve new user registrations
- Role-based access control (Admin/User)

### 2. Adding Calves
- Navigate to Calves → Add New Calf
- System auto-generates unique Calf ID
- Events are automatically scheduled based on birth date

### 3. Batch Management
- Create batches with capacity limits
- Visual color coding: Green (≤5), Orange (6-9), Red (≥10)
- Move calves between batches

### 4. Task Management
- View due tasks on dashboard
- Mark tasks as complete with one click
- Automatic event scheduling based on calf age

### 5. Feeding Calculator
- Calculate milk requirements
- View preparation instructions
- Track weaning progress

### 6. Electrolyte Management
- Mark calves needing electrolytes
- 3-day treatment scheduling
- Progress tracking

## Mobile Usage
The application is fully mobile-responsive. Key mobile features:
- Quick task completion
- Add new calves
- Health status updates
- Batch viewing
