# EasyCalf Installation Guide

## Requirements
- PHP 8.0 or higher
- MySQL 5.7 or higher
- Web server (Apache/Nginx)

## Installation Steps

1. **Upload Files**
   - Upload all EasyCalf files to your web hosting
   - Ensure file permissions: 755 for directories, 644 for files

2. **Create Database**
   - Create a MySQL database for EasyCalf
   - Note database name, username, and password

3. **Run Installer**
   - Navigate to `yourdomain.com/install`
   - Follow the installation wizard
   - Enter database credentials and base URL

4. **Complete Installation**
   - The installer will create all tables and default admin user
   - Default admin login: admin@easycalf.com / admin123

5. **Secure Installation**
   - Delete or rename the `install` directory
   - Configure proper file permissions

## Default Login
- Email: admin@easycalf.com
- Password: admin123

**Important**: Change the default password after first login!
